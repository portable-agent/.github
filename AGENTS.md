# Правила для AI-агентов

## Назначение

Репозиторий хранит общие настройки GitHub-организации Portable Agent. Он не содержит бизнес-код.

## Границы

- Не добавляй сюда код отдельного сервиса.
- Общий workflow должен подходить нескольким репозиториям.
- Не добавляй секреты, имена окружений и правила бизнеса.
- Изменение общего workflow может сломать сразу несколько репозиториев: сохраняй обратную совместимость.

## Структура

- `.github/workflows/` — общие CI/CD-процессы.
- `.github/ISSUE_TEMPLATE/` — шаблоны задач.
- `profile/` — профиль организации.
- `docs/` — документация этого репозитория.
- `scripts/` — небольшие проверки без лишних зависимостей.

## Команды

```powershell
pwsh ./scripts/check-docs.ps1
```

## Правила изменений

1. Пиши документацию по-русски и короткими предложениями.
2. В именах кода используй простой английский уровня A2: `create`, `find`, `save`, `status`, `request`.
3. Не используй редкие сокращения и сложные слова, если есть простое название.
4. Сначала добавь проверку или тест, затем изменение, затем приведи код в порядок.
5. Обновляй README, `docs/` и шаблоны в том же pull request.
6. Для решения, которое влияет на несколько реп, добавь ADR в `portable-agent/platform`.
7. Перед завершением запусти доступные проверки и запиши результат в pull request.
