# Portable Agent

Portable Agent — открытая платформа персональных AI-агентов, которую можно встраивать в Telegram,
web, mobile и другие клиентские поверхности. Агент понимает голосовые и текстовые команды,
показывает переносимые виджеты подтверждения и безопасно выполняет действия через MCP-коннекторы.

- [Архитектура и документация](https://portable-agent.github.io/platform/)
- [Platform repository](https://github.com/portable-agent/platform)
- [Как участвовать](https://github.com/portable-agent/.github/blob/main/CONTRIBUTING.md)

Проект развивается публично. Высокорисковые действия всегда проектируются с preview,
явным подтверждением, policy checks и аудитом.
