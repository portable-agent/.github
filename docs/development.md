# Разработка

## Порядок работы

1. Создайте небольшую ветку.
2. Для изменения поведения сначала добавьте проверку, которая показывает ожидаемый результат.
3. Внесите минимальное изменение.
4. Запустите проверку документации.
5. Обновите описание, если поменялись команды или границы.

## Имена

Используйте простой английский. Хорошие слова: `get`, `find`, `create`, `save`, `send`, `check`, `result`.
Не используйте длинные термины, если короткое имя сохраняет смысл.

## Локальная проверка

```powershell
pwsh ./scripts/check-docs.ps1
```

Новый общий workflow также проверяется в тестовом репозитории до обязательного включения для всех сервисов.
