# Диагностика

## Общий CI не запускается

1. Проверьте путь и версию после `uses:` в репозитории сервиса.
2. Проверьте, что общий workflow содержит событие `workflow_call`.
3. Проверьте доступ GitHub Actions к публичному репозиторию `.github`.

## Проверка документации упала

Запустите локально:

```powershell
pwsh ./scripts/check-docs.ps1
```

Сообщение укажет отсутствующий файл или раздел. Не отключайте проверку: добавьте короткое актуальное описание.

## Изменение сломало несколько реп

Верните совместимый вариант общего workflow или выпустите новую версию. Создайте задачу миграции для каждой
затронутой репы и опишите решение ADR в `portable-agent/platform`.
