# Устройство репозитория

GitHub автоматически использует часть файлов из специальной репы `.github`. Другие репозитории явно
вызывают общие workflows по ссылке на версию.

```text
portable-agent/.github
├── profile                 профиль организации
├── .github/workflows       общие CI/CD-процессы
├── .github/ISSUE_TEMPLATE  общие шаблоны задач
├── docs                    правила организации
└── scripts                 лёгкие проверки
```

Общий workflow не должен знать устройство бизнес-кода. Нужные отличия передаются через простые входные
параметры. Специальные правила остаются в репозитории сервиса.

Container workflow имеет два режима. В pull request образ загружается в локальный Docker для проверки
Trivy, поэтому SBOM и provenance не создаются. После изменения `main` образ публикуется в GHCR вместе с
SBOM, максимальным provenance, attestation и подписью Cosign.
