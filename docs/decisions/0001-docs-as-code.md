# Решение 0001: документация хранится рядом с кодом

- Статус: принято
- Дата: 2026-08-28

## Решение

Каждая репа хранит README, инструкции для AI-агентов, подробные Markdown-документы и карточку Backstage.
Изменение кода и связанной документации выполняется в одном pull request.

## Причина

Так человеку и AI-агенту не нужно заново исследовать сервис перед каждой задачей. История текста проходит
то же ревью, что и код.

## Последствия

CI проверяет наличие основных файлов и полей. Владелец репозитория отвечает за смысл и актуальность текста.
