# Общие настройки GitHub

Репозиторий задаёт общие правила для независимых репозиториев Portable Agent.

## Быстрый старт

1. Прочитайте [устройство репозитория](architecture.md).
2. Перед изменением откройте [правила разработки](development.md).
3. При сбое общего CI используйте [инструкцию по диагностике](runbook.md).

## Обязательные файлы в каждой репе

- `README.md` — короткий ответ: что это и как запустить.
- `AGENTS.md` — границы и команды для будущих AI-агентов.
- `catalog-info.yaml` — карточка Backstage.
- `mkdocs.yml` и `docs/` — подробная документация.
- `docs/architecture.md` — устройство и зависимости.
- `docs/development.md` — локальная разработка и тесты.
- `docs/runbook.md` — запуск и поиск проблем.
- `docs/decisions/` — решения, важные только для этой репы.

Решения, которые меняют несколько репозиториев, хранятся как ADR в `portable-agent/platform`.
